# Nicolas Riveiro Quintans · Portfolio

Static portfolio site (plain HTML/CSS/JS, no build step).

## Publish on GitHub Pages
1. Create a repo named `<your-username>.github.io` (or any name).
2. Upload everything in this folder (keep the folder structure).
3. Repo **Settings → Pages → Deploy from branch → main / root**.

## Structure
- `index.html` home page (hero video, about, projects, experience, resume, contact)
- `projects/*.html` one detail page per project
- `css/style.css`, `js/main.js` shared styles and interactions
- `assets/` video, images and resume PDF

To swap the resume, replace `assets/docs/Nicolas-Riveiro-Resume.pdf` and `assets/img/resume-preview.png`.
